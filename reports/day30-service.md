# День 30: локальная LLM как приватный сервис — проверки

**Дата:** 2026-10-10
**Скрипт проверок:** `Projects/ai-challenge-9/mcp-servers/day30_check.py` (JSON-сырца: `mcp-servers/.day30-check.json`)
**Стек:** LM Studio `:1235` (`qwen3-8b-mlx`) + RAG-sidecar `gwclub serve` `:18700` + `bot_responder.py`

## 1. Доступ к модели по сети

- LM Studio слушает **`127.0.0.1:1235`** (только loopback) — подтверждено `lsof`.
- Для доступа из LAN/VPS: LM Studio → Developer → «Serve on Local Network» (bind `0.0.0.0`) + при необходимости проброс порта/файрвол. Вне доверенной сети обязательно ставить reverse-proxy с авторизацией (API не имеет встроенной аутентификации).
- RAG-sidecar по умолчанию тоже bind `127.0.0.1:18700` — для сетевого доступа аналогично `--host 0.0.0.0`.

## 2. Стабильность при нескольких запросах

| Тест | Параллельно | OK | Отказы | Пустые ответы | Latency mean / max | Wall |
|---|---|---|---|---|---|---|
| Генерация LM Studio | 5 | 5/5 | 0 | 0 | 2.02 с / 2.58 с | 2.6 с |
| Поиск RAG sidecar | 5 | 5/5 | 0 | — | 0.163 с | 0.18 с |

LM Studio выстраивает параллельные запросы в очередь без отказов; бот дополнительно сериализует генерацию внутренней очередью (один worker на LLM), а пользователей ограничивает rate limit'ом.

## 3. Базовые ограничения

- **Max context:** модель `qwen3-8b-mlx` — 40960 токенов. Проверен ввод ~9257 токенов: обработан корректно (`finish_reason=stop`), латентность 44 с (обработка длинного ввода существенно медленнее коротких запросов — при таком объёме бюджет ответа бота ≤60 с на исходе, поэтому в боте длинные вопросы не ожидаются; лимит задокументирован).
- **Rate limit бота:** `COOLDOWN_SEC=5.0` в `bot_responder.py` — не более 1 запроса от пользователя в 5 секунд, иначе «Подождите немного…». Глобальная очередь — LLM обрабатывается последовательно.
- **Reasoning-бюджет:** `max_tokens ≥ 1024` обязателен (см. `reports/optimization.md`), при пустом `content` и `finish_reason=length` бот делает один ретрай с удвоенным лимитом.

## 4. Запуск стека одной командой

```sh
cd Projects/ai-challenge-9/mcp-servers
./start_stack.sh   # проверит LM Studio, поднимет gwclub serve и bot_responder (идемпотентно)
./stop_stack.sh    # остановка по PID-файлам
```
