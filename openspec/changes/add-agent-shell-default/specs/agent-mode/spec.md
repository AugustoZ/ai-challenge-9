# Spec: Агент по умолчанию (маршрутизация свободного текста)

## ADDED Requirements

### Requirement: Маршрутизация свободного текста в личке
Свободный текст в личном чате (после перехвата активной сессии агента и
без-LLM интентов deps/файл/create) ДОЛЖЕН маршрутизироваться
LLM-классификатором «это вопрос по документации/проекту?» (ДА/НЕТ,
max_tokens 8, `/no_think`): ДА → `ask` (RAG), НЕТ → создание агентной
сессии (как `/agent <текст>`: клавиатура модели → цикл → гейт). Сбой
транспорта, пустой или неразобранный ответ классификатора ДОЛЖНЫ
обрабатываться как «ДА» (вопрос → RAG — безопасный фолбэк, прежнее
поведение). `/agent` и `/ask` остаются явными переключателями; группы
не затрагиваются.

#### Scenario: Императив уходит агенту
- **WHEN** пользователь написал «сделай в проекте новую ветку lesson_36»
- **THEN** классификатор ответил «НЕТ» → создана агентная сессия,
  показан выбор модели

#### Scenario: Вопрос уходит в RAG
- **WHEN** пользователь написал «почему не работает судья?»
- **THEN** классификатор ответил «ДА» → обычный RAG-ответ

#### Scenario: Сбой классификатора
- **WHEN** LLM недоступна или ответ пустой/неразборчив
- **THEN** текст обработан как вопрос (RAG) — прежнее поведение

#### Scenario: Явные команды приоритетны
- **WHEN** пользователь написал `/ask …` или `/agent …`
- **THEN** классификатор не вызывается, срабатывает явный режим

#### Scenario: Порядок защиты
- **WHEN** текст матчит deps-интент, файл-интент или create-интент
- **THEN** классификатор не вызывается (без-LLM пути дешевле классификации)

#### Scenario: Активная сессия агента
- **WHEN** сессия агента активна (TASK_SET/MODEL_SELECT/AWAIT_CONFIRM)
- **THEN** текст перехватывается сессией как раньше, классификатор молчит

#### Scenario: Без каталога моделей
- **WHEN** config.json не содержит валидных `agent.models`
- **THEN** классификатор не вызывается, весь свободный текст → RAG
  (текущее поведение)
