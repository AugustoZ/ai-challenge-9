## 1. Триггер создания задачи (задача 2)

- [x] 1.2 Явное намерение вне счётчиков: (отказ от плана: «без плана» /

  «реализац» / «пиш» / «сдела» / «интегр») → intent; плюс «пиши»-слово
  + код-слово (код/реализац/интегр) → intent

  нужен, сразу пиши код…», «Без плана, сразу код», «пиши код для
