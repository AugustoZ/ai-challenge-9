# Spec: Интент «создай issue» из свободной фразы

## ADDED Requirements

### Requirement: Распознавание интента создания
Бот ДОЛЖЕН распознавать свободную фразу, начинающуюся с глагола создания
(«создай», «заведи», «оформи», «поставь», «заполни», «зарегистрируй» и формы
инфинитива), и решать, просит ли пользователь создать issue.

#### Scenario: Явный контекст
- **WHEN** фраза «создай Issue на ошибку авторизации в AuthGate» (в личке)
- **THEN** бот сразу переводит фразу в черновик issue (как `/create <описание>`),
  не тратя токены на классификацию

#### Scenario: Контекст неоднозначен
- **WHEN** фраза начинается с глагола создания, но слов контекста нет
- **THEN** бот спрашивает локальную LLM (ответ одним словом ДА/НЕТ);
  «ДА» → черновик issue, «НЕТ» → обычный RAG-ответ

#### Scenario: Не создание
- **WHEN** фраза «создавалась ли ошибка авторизации?»
- **THEN** интент не срабатывает (прошедшее время), вопрос идёт в RAG

### Requirement: Защита существующих интентов
Распознавание НЕ ДОЛЖНО перехватывать фразы других интентов.

#### Scenario: «Создай карту зависимостей»
- **WHEN** LLM-классификатор ответил «НЕТ»
- **THEN** вопрос идёт в `_handle_ask`, где deps-интент строит PNG без RAG

### Requirement: Гардрейлы /create
Интент ДОЛЖЕН работать только в личном чате и создавать черновик
(финализация — явное `/create`), как и команда.

#### Scenario: Групповой чат
- **WHEN** фраза «создай issue…» написана в группе (даже с @упоминанием)
- **THEN** issue не создаётся, бот отвечает как на обычный вопрос
