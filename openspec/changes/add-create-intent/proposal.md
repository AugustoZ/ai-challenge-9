# Change: Интент «создай issue» из свободной фразы

## Зачем

Команда `/create` работает только по явной команде: фраза «создай Issue на
ошибку авторизации в зависимости auth/AuthGate» уходит в RAG, и бот
пересказывает документацию вместо создания issue. Хочется: свободная фраза с
глаголом создания передаётся в LLM, и если по контексту это issue/задача/
ошибка — вызывается тул `/create`.

## Ключевые решения

| Решение | Выбор | Почему |
|---|---|---|
| Триггер | Глагол создания В НАЧАЛЕ фразы (создай/создайте/создать, заведи/завести, оформи/оформить, зарегистрируй, поставь, заполни) | Отсекает прошедшее время («создавалась ли ошибка») и вопросы в середине фразы |
| Быстрый путь | Глагол + слово контекста (issue, задач, баг, ошибк, тикет, дефект, фич, улучшени…) → сразу `Route("create", остальное)` | Детерминированно, без траты токенов |
| Медленный путь | Глагол без слов контекста → режим `create_check`: локальная LLM отвечает ДА/НЕТ на вопрос «просит ли пользователь создать issue» | Покрывает парафразы («заведи карточку», «создай запись в гитхабе»); «НЕТ» → обычный RAG-ответ |
| LLM-классификатор | `_post_chat`, system-промт «одним словом ДА или НЕТ», max_tokens 8, /no_think | reasoning отключён серверно; сбои транспорта → НЕТ (не блокируем вопрос) |
| Защита от ложных срабатываний | «создай карту зависимостей» → без слов контекста → LLM «НЕТ» → `_handle_ask`, где первым работает deps-интент | deps-интент в `_handle_ask` не трогаем |
| Где работает | Только личный чат | Гардрейл `/create` не меняем: черновик + файлы — личный сценарий |
| Аргумент create | Текст после глагола (без него) | В `/create` уже приходит описание; LLM issue_create строит TITLE:/BODY: |
| Двухшаговость | Сохраняется: фраза создаёт ЧЕРНОВИК, финализация — `/create` | Существующий флоу с приложением файлов не ломаем |

## Edge cases

- Глагол в начале, но вопрос («создавалась ли ошибка…») → не матчится (форма прошедшего времени).
- «Создай карту зависимостей» → LLM «НЕТ» → deps-интент строит PNG как раньше.
- LLM-классификатор недоступен (таймаут/ошибка) → считаем «НЕТ», вопрос идёт в RAG.
- Пустой остаток после глагола → медленный путь с полным текстом.
- Групповой чат → интент не активен (создание issue — только личка).

## Волны

1. Регексы `_CREATE_VERB_RE`/`_CREATE_CTX_RE`, промт-классификатор, `_handle_create_check`, проводка в `_route_message` (личка) и `_handle_job`, справка.
2. Верификация: py_compile, inline-смоки (регексы, роутинг, классификатор, хендлер), деплой на прод-поллер, проверка лога.
