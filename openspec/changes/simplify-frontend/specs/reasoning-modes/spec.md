# Спецификация: reasoning-modes

> Дельта change `simplify-frontend`. Новая capability — фиксация
> целевого состояния: способ рассуждения один, выбора нет.

## ADDED Requirements

### Requirement: Единственный способ рассуждения — «Агент»

Приложение имеет ровно один способ обработки запроса — агентный цикл
(`AgentLoop`). Сервер не принимает и не разбирает выбор режима: поле
`reasoningMode` в `ChatRequest` отсутствует, dispatch по режимам
удалён, оба маршрута `/api/chat` и `/api/chat/stream` всегда ведут в
агентный путь.

#### Scenario: Запрос обрабатывается агентом

- КОГДА POST `/api/chat` или `/api/chat/stream` без поля `reasoningMode`
- ТОГДА запрос обрабатывается агентным циклом
- И ответ содержит события агента (`events`)

#### Scenario: Устаревшее поле режима игнорируется

- КОГДА клиент присылает `reasoningMode` (старый фронт до flip,
  curl из документации прошлых версий)
- ТОГДА незнакомое поле игнорируется при десериализации, ошибка не
  возвращается
- И запрос обрабатывается агентным циклом

### Requirement: Сессия всегда привязана к запросу

Каждый запрос работает с сессией (прежнее поведение агентного режима):
история, стратегии контекста и ветки действуют на каждом запросе;
stateless-путей больше нет. Guard активации ветки не зависит от
какого-либо режима.

#### Scenario: Первый запрос создаёт сессию

- КОГДА запрос приходит без `sessionId`
- ТОГДА создаётся сессия и возвращается её идентификатор
- И последующие запросы с этим `sessionId` видят общую историю

### Requirement: Интерфейс без переключателя режимов

Новый интерфейс (React) не содержит выбора режима: нет панели
«Способ рассуждения», бейджа режима в шапке, упоминаний режимов в
приветственном тексте и подсказках (в том числе топливомера).
Запросы не несут `reasoningMode`.

#### Scenario: Интерфейс без выбора режима

- КОГДА открывается страница приложения
- ТОГДА панель «Способ рассуждения» и бейдж режима отсутствуют
- И приветственный текст описывает агентную работу, не перечисляя режимов

#### Scenario: Запрос без поля режима

- КОГДА пользователь отправляет сообщение
- ТОГДА payload запроса не содержит `reasoningMode`
