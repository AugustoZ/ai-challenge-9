# Spec: Доступ бота к файлам проекта (выдача файла документом)

## ADDED Requirements

### Requirement: Read-only доступ к дереву проекта
Модуль `project_files.py` ДОЛЖЕН давать боту доступ только на чтение к дереву
корня проекта (`PROJECT_FILES_ROOT`, дефолт — корень ai-challenge-9) и НЕ ДОЛЖЕН
позволять выйти за пределы корня.

#### Scenario: Путь внутри корня
- **WHEN** запрошен `src/main/kotlin/com/example/aiweb/routes/Routes.kt`
- **THEN** файл читается и возвращается текст

#### Scenario: Попытка выхода за корень
- **WHEN** запрошен путь с `..` или абсолютный путь вне корня
- **THEN** резолв возвращает «не найдено», чтение не выполняется

#### Scenario: Бинарный файл
- **WHEN** запрошен файл с бинарным расширением или с NUL-байтами
- **THEN** чтение отказывает с явной причиной

### Requirement: Прямой интент «покажи файл»
Бот ДОЛЖЕН ловить свободную фразу «(покажи|пришли|скинь|отправь|дай) файл <имя>»
до RAG-пайплайна и присылать найденный файл документом без вызова LLM.

#### Scenario: Однозначный файл
- **WHEN** по имени запроса найден ровно один файл (или точное совпадение имени)
- **THEN** бот присылает документ с caption «Файл: <путь>» и закрывает запрос

#### Scenario: Несколько кандидатов
- **WHEN** найдено несколько подходящих файлов без явного лидера
- **THEN** бот присылает список путей и просит уточнить

#### Scenario: Ничего не нашли
- **WHEN** по имени ничего не найдено
- **THEN** вопрос продолжается обычным RAG-ответом (не отказ)

### Requirement: Выдача файла по решению LLM
Когда вопрос похож на «покажи/пошли файл/как устроена возможность», в RAG-промпт
ДОЛЖНО добавляться правило: последней строкой ответа вывести
`<file>путь/от/корня/проекта</file>`; бот ДОЛЖЕН вырезать маркер, прочитать файл
и прислать его документом.

#### Scenario: Модель назвала валидный путь
- **WHEN** ответ содержит `<file>src/main/kotlin/.../Routes.kt</file>`
- **THEN** маркер вырезан из текста, файл прислан документом с путём в caption

#### Scenario: Модель назвала только имя файла
- **WHEN** маркер содержит `Routes.kt` без пути
- **THEN** путь восстанавливается поиском по имени файла в дереве проекта

#### Scenario: Файл не найден
- **WHEN** файл по маркеру не резолвится
- **THEN** к текстовому ответу добавляется «Не нашёл файл «X» в проекте.»

### Requirement: Ограничения выдачи
Бот ДОЛЖЕН ограничивать выдачу: не более 2 файлов на один ответ и не более
300 000 символов текста на файл.

#### Scenario: Модель запросила 3 файла
- **WHEN** в ответе три маркера `<file>`
- **THEN** отправлены первые два
