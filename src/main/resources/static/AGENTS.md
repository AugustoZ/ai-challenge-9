# STATIC FRONTEND KNOWLEDGE BASE

Vanilla JS/CSS фронт «Штурмана»: приборная доска кокпита. Обслуживается Ktor как static, сборщика нет. Дизайн-контракт — `DESIGN.md` в корне репо (палитра, шрифты B612/B612 Mono, история приращений).

## STRUCTURE
- `index.html` (~160 стр.) — вся разметка: шапка-приборка, панель настроек (круглые шкалы, клавиши-табло, стоп-фраза), чат, самописец.
- `style.css` (~1740 стр.) — визуальная система; токены в `:root` (включая ламповые `--lamp-*`).
- `script.js` (~740 стр.) — движок шкал-крутилок, тултипы, самописец, отправка чата.

## WHERE TO LOOK
| Задача | Location |
|---|---|
| Цвета/свечение/лампа-формулы | style.css → секция `:root` (токены, включая параметрический `--lamp-rgb`) |
| Круглые шкалы: геометрия, зоны, drag | script.js → конфиг `DIALS`, `zoneLevel()`, `arcBetween()` |
| Клавиатурная доступность шкал | script.js: скрытые `<input type=range>` + `aria-valuetext` |
| Тултипы «?» | index.html (`.info-btn` + `.tooltip`) + script.js (клик-пин/Escape) |
| Самописец (журнал обменов) | script.js → fetch `/api/log`, рендер `.rec-entry` |
| Сохранение настроек | script.js → localStorage `ai-assistant.settings.v1` |

## CONVENTIONS
- Новые цвета — только CSS-токены из `:root`/DESIGN.md. Запрещены хардкод-хексы в новых правилах.
- Палитра-роли: янтарь — управление/активное, зелёный — показания, красный — отказы/опасность.
- Шрифты только B612 (текст) / B612 Mono (цифры, значения).
- Пользовательские тексты — на русском.

## ANTI-PATTERNS (THIS PROJECT)
- `data-setting` живёт на элементе `.dial`, НЕ на `.gauge` — частый источник багов в селекторах.
- Не дублируй значение шкалы для скринридера: цифры `.dial-value` имеют `aria-hidden="true"`, озвучивание — только через `aria-valuetext` скрытого range.
- Не ломай контракт скрытого range: он источник клавиатурного управления и PageUp/PageDown (±10 позиций).
- Геометрия шкал: `GAUGE_START=225`, `GAUGE_SWEEP=270` — не менять без пересчёта дуг зон и drag-логики.
- Зоны допуска задаются точными включительными диапазонами в `DIALS` (см. DESIGN.md) — не «сглаживать» границы.
- Hit-область «?» (25px через `::before`, WCAG 2.5.8) и hoverable-тултипы (мост `::after` + `:has(.tooltip:hover)`, WCAG 1.4.13) — не удалять: выглядят как мёртвый код, но это контракты доступности.
